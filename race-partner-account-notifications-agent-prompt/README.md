# RACE Partner Account & Notifications Agent Prompt

This package contains one copy-paste master prompt and the two visual reference boards supplied for it.

## Files
- `MASTER_PROMPT.md` — use this as the agent task prompt.
- `references/reference-board-01-account-settings.png` — broad account/settings/notifications pattern board.
- `references/reference-board-02-profile-earnings-notifications.png` — profile, documents, earnings, notifications, vehicle, trip history and logout reference board.

## How to use
1. Put the package or the master prompt into the coding agent's context.
2. Attach the original RACE Partner architecture/audit document and the existing RACE motion/interaction standard if you have them available in the project.
3. Give the agent access to the actual repository.
4. Ask it to audit current routes/APIs before coding; the prompt explicitly prohibits inventing unsupported backend behavior or treating design sample data as production data.
