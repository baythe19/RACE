# learnings (do not repeat)

- **Metro restart trap (2026-10-17):** `pkill -f "expo start"` inside a Shell tool call **kills the agent's own shell too** (the command string matches itself) → Metro silently never comes back, next curl shows 000. Fix: skip pkill; if a port is stuck, kill by PID from `ss -tlnp | grep :8082` first, then start with `setsid npx expo start --port 8082 … & disown`. Also: `CI=true` env (e.g. inherited) puts Expo in "CI mode, reloads disabled" — start with plain `setsid npx expo start` (no CI) or `env -u CI`. Check health: log `/tmp/metro-8082.log` + `curl http://localhost:8082/status` 200.
- **Peach Codespace Cursor Browser (2026-10-17, FIXED):** Repeated sootsim redbox `could not reach fetch proxy at https://127.0.0.1:33059` is NOT fixed by re-running `peach open`. On Codespace, Cursor Browser cannot use `fetchProxyOrigin=127.0.0.1:33059`. Working sequence: (1) Metro detached on 8082 status 200; (2) `browser_navigate` a **proxy-free** `…/rn?bundle=http://localhost:8082/index.ts.bundle…` URL (**no fetchProxyOrigin**, host `localhost` not `127.0.0.1`); (3) verify Browser screenshot + `peach describe` on the **new** sim (`loaded: bundle localhost:8082`). CLI sims can show Welcome while the user tab is still redboxed — always check the Browser. Docs: `docs/DEVICE_FREE_PREVIEW.md` + `activeContext.md` § PROVEN RUNBOOK.
- **Expo tunnel redbox (Oct 2026):** `Cannot connect to Expo CLI` on `*.exp.direct:80` is the hot-reload socket, not the API. `ExpoAsset.downloadAsync` on splash (`golden-sunrise-tow-truck-highway.png`) must be caught — a tunnel blip becomes an uncaught rejection even when Metro returns 200.
- **Peach browser simulator (Oct 2026):** Device-free app preview on this Codespace — installed at `~/.local/bin/peach`, full guide in `docs/DEVICE_FREE_PREVIEW.md`. Both apps compatible (customer: 16 supported; partner: 13 supported; only `expo-location` 80% + `expo-status-bar` inert). Run: `expo start` → `peach open 8081|8082` → view at `localhost:7668`. Agent verbs `peach describe/tap/screenshot/assert` verified live (onboarding taps worked). Metro terminal may show a harmless `libatk-1.0.so.0` DevTools redbox — ignore it.

- **RACE UI/UX & Motion Standard (Oct 2026):** All screens scale against `REF_W = 390` with clamped scale `Math.min(1.22, Math.max(0.88, width / REF_W))`. Standard header height `insets.top + px(58)` with `<PartnerHeaderLogo width={px(104)} />`. ScrollViews must set `keyboardDismissMode="on-drag"` and `keyboardShouldPersistTaps="handled"`. Indian mobile inputs must strip `+91`/`0` prefixes. Motion tokens live in `theme/motion.ts` (100ms tap feedback, 280ms screen transition). Driver registration routes through 4 steps to `DriverVerificationPendingScreen` (vertical status tracker matching image copy 4.png). Details documented in `.agents/rules/ui-consistency-patterns.md` and ADR-010.
