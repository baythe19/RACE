# learnings (do not repeat)

- **Driver offer types (2026-10-29):** The hire feed matches `Part-Time` / `Full-Time` / `Tow Driver` only. A profile saved as `Driver Service` is invisible unless `selfDriverCategory` is loaded and mapped. Independent drivers never see towing offers. Vendor assign needs the fleet driver `isAvailable: true`.

- **Driver nav (2026-10-20):** Google/OSRM steps describe the maneuver at the **start** of a step. The banner must count down to the **next** step. A pickup that sits off the road is not off-route until the driver has joined the road (`JOIN_ROAD_METERS` in `useDriverRoute.ts`). Preview trip OTP is `1234`. Peach draws markers but not polylines, and a source save reloads the app and resets mock trip state. Trip-in-progress contact actions are call-only.
- **Next machine:** MCP plugins are not in git. Reconnect list is `docs/ops/CURSOR_MCP_SETUP.md`. Do not copy tokens into the repo.

- **Location permission (partner app, 2026-10-19):** App must not remember a one-time denial — call `ensureForegroundLocationPermission()` / `getCurrentPositionWhenAllowed()` from `mobile application/src/utils/locationPermission.ts` whenever a feature needs GPS (registration address focus, map “current location”, driver location reporting). OS may still block repeat system dialogs after “Don’t allow”; that is platform behavior, not an in-app “never ask again” flag.
- **Peach/sootsim stale parse errors (2026-10-29):** Line numbers like DriverPickup `recentPickups` at 355, `goBackWithinStack` return at 53, or `MAP_PROVIDER already declared` can be **old HMR snapshots**. If `tsc --noEmit` is 0 and tag counts balance, do not rewrite valid JSX — `npx expo start --port 8081 --clear` and reload the sim. `dev server unreachable` means Metro died (check :8081), not a syntax bug.
- **Unhandled Axios 401 (2026-10-29):** `void fetchProfile()` + `throw error` in `profileStore` surfaces as `unhandled rejection: AxiosError 401`. Swallow fetch errors like `vehicleStore`; skip authed GETs when there is no token; gate React Query with `enabled: isAuthenticated`.
- **Metro restart trap (2026-10-17):** `pkill -f "expo start"` inside a Shell tool call **kills the agent's own shell too** (the command string matches itself) → Metro silently never comes back, next curl shows 000. Fix: skip pkill; if a port is stuck, kill by PID from `ss -tlnp | grep :8082` first, then start with `setsid npx expo start --port 8082 … & disown`. Also: `CI=true` env (e.g. inherited) puts Expo in "CI mode, reloads disabled" — start with plain `setsid npx expo start` (no CI) or `env -u CI`. Check health: log `/tmp/metro-8082.log` + `curl http://localhost:8082/status` 200.
- **Peach Codespace Cursor Browser (2026-10-17, FIXED):** Repeated sootsim redbox `could not reach fetch proxy at https://127.0.0.1:33059` is NOT fixed by re-running `peach open`. On Codespace, Cursor Browser cannot use `fetchProxyOrigin=127.0.0.1:33059`. Working sequence: (1) Metro detached on 8082 status 200; (2) `browser_navigate` a **proxy-free** `…/rn?bundle=http://localhost:8082/index.ts.bundle…` URL (**no fetchProxyOrigin**, host `localhost` not `127.0.0.1`); (3) verify Browser screenshot + `peach describe` on the **new** sim (`loaded: bundle localhost:8082`). CLI sims can show Welcome while the user tab is still redboxed — always check the Browser. Docs: `docs/DEVICE_FREE_PREVIEW.md` + `activeContext.md` § PROVEN RUNBOOK.
- **Peach runtime hex prefix (2026-10-30):** Engine URL host prefix = hex(runtime version) — `0.1.1822` → `302e312e31383232`. After a Peach engine upgrade the OLD prefix's host stops resolving in the user Browser (silently, title stays blank/"Peach" with no sim registered). Compute fresh: `python3 -c "print('<ver>'.encode().hex())"` from `activeRuntime` in `~/.peach/daemon.json`. Customer-browser PROVEN URL (2026-10-30, sim `1c0c752e…`): `http://302e312e31383232.runtime.localhost:7668/rn?bundle=http%3A%2F%2Flocalhost%3A8081%2Findex.ts.bundle%3Fplatform%3Dios…&expoSwift=http%3A%2F%2Flocalhost%3A7668%2F__peach%2Fexpo-swift%3Froot%3D…customer%2520application&expoKotlin=…&orientation=portrait&landscapeSide=left` — NO fetchProxyOrigin, NO launchMetadata, NO packageVersions. Peach preview publish (`peach preview`) needs peachsim.com OAuth whose callback hits the USER machine's localhost, not the codespace — dead end on Codespace; don't retry. GitHub port-forward (`gh cs ports forward 7668`) also fails: VS Code already binds 7668 locally.
- **Expo tunnel redbox (Oct 2026):** `Cannot connect to Expo CLI` on `*.exp.direct:80` is the hot-reload socket, not the API. `ExpoAsset.downloadAsync` on splash (`golden-sunrise-tow-truck-highway.png`) must be caught — a tunnel blip becomes an uncaught rejection even when Metro returns 200.
- **Peach browser simulator (Oct 2026):** Device-free app preview on this Codespace — installed at `~/.local/bin/peach`, full guide in `docs/DEVICE_FREE_PREVIEW.md`. Both apps compatible (customer: 16 supported; partner: 13 supported; only `expo-location` 80% + `expo-status-bar` inert). Run: `expo start` → `peach open 8081|8082` → view at `localhost:7668`. Agent verbs `peach describe/tap/screenshot/assert` verified live (onboarding taps worked). Metro terminal may show a harmless `libatk-1.0.so.0` DevTools redbox — ignore it.

- **RACE UI/UX & Motion Standard (Oct 2026):** All screens scale against `REF_W = 390` with clamped scale `Math.min(1.22, Math.max(0.88, width / REF_W))`. Standard header height `insets.top + px(58)` with `<PartnerHeaderLogo width={px(104)} />`. ScrollViews must set `keyboardDismissMode="on-drag"` and `keyboardShouldPersistTaps="handled"`. Indian mobile inputs must strip `+91`/`0` prefixes. Motion tokens live in `theme/motion.ts` (100ms tap feedback, 280ms screen transition). Driver registration routes through 4 steps to `DriverVerificationPendingScreen` (vertical status tracker matching image copy 4.png). Details documented in `.agents/rules/ui-consistency-patterns.md` and ADR-010.

- **Customer double-tap / skeleton (2026-10-29):** Use `DataSkeleton` (`components/ui/DataSkeleton.tsx`) on first-load data pages instead of bare ActivityIndicator. Mutation handlers need both `disabled={isPending}` AND early `if (isPending) return` — Pressable can fire before React re-renders. Zustand GET helpers (profile/vehicles/catalog) should share an in-flight Promise so remounts do not stack duplicate calls.
